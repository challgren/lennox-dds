# `custom_components/`

Home Assistant custom components published by this repo.

- [`lennox_dds/`](lennox_dds/README.md) — the Lennox iComfort DDS integration (a
  `local_push` WebSocket client for the DDS bridge add-on). See its README for
  entities, setup, and layout.

HACS installs this integration from here; the add-on that it pairs with lives in
[`../lennox_dds/`](../lennox_dds/README.md) and its image source in
[`../container/`](../container/README.md).
