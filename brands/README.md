# Home Assistant brands submission (integration icon)

These are ready to drop into a PR against
[home-assistant/brands](https://github.com/home-assistant/brands) so the
`lennox_dds` integration shows a real icon/logo in Settings → Devices & Services
(instead of the generic placeholder).

Copy `custom_integrations/lennox_dds/` into the brands repo's
`custom_integrations/` folder and open a PR. Requirements met: `icon.png`
(256×256), `icon@2x.png` (512×512), `logo.png`, `logo@2x.png`. Original artwork —
not Lennox's trademarked branding.
